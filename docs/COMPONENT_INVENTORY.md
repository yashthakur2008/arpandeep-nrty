# Component Inventory: what is used where

Status after the architecture refactor of 2026-09-05. Generated by reading every
file in the repository, not from prior documentation.

## Active code (`loki/`)

| Module | Used by | Purpose |
|---|---|---|
| `config.py` | trainers, eval | `TrainingConfig`. Precedence: defaults < `runpod_config.yaml` < `LOKI_*` env < CLI. Validates before any expensive work. |
| `runtime.py` | trainers, eval | Logging, seeding, wandb lifecycle, **preflight** credential/server check. |
| `data/harmbench.py` | trainers, eval, tests | Reads `scripts/harmbench_behaviors_text_all.csv` (400 behaviors), renders Jinja prompts, emits TRL conversational dataset. Seeded sampling. |
| `prompts/harmbench_system.j2` | `data/harmbench.py` | Attacker system prompt: 3 few-shot examples, demands `<reasoning>`/`<misdirection>` tags. |
| `prompts/harmbench_user.j2` | `data/harmbench.py` | Per-behavior user prompt. |
| `rewards/parsing.py` | reward, eval | Normalizes TRL completion shapes; extracts misdirection (strict tag or label fallback). |
| `rewards/targets.py` | reward, eval | **The model being attacked.** `EchoTarget` (stub) / `OllamaTarget` / `OpenAITarget`. |
| `rewards/judges.py` | reward, eval | **Did the target refuse?** `RefusalHeuristicJudge` / `OllamaJudge` / `OpenAIJudge`. |
| `rewards/harmbench.py` | trainer | The single GRPO reward: `0.2*format + 0.2*quality + 0.6*attack`. |
| `trainers/grpo.py` | `loki-train` | GRPO training via TRL. |
| `eval.py` | `loki-eval` | ASR + format rate with bootstrap CIs. Does not update weights. |
