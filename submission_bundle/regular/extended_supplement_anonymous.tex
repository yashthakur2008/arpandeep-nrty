\section{Purpose of the supplement}
This supplement supports the regular-paper submission without adding main-paper pages. It documents the scenario inventory, policy variants, attack families, result artifacts, and acceptance-path checks. It is anonymous and contains no author-identifying paths or credentials.

\section{Policy variants}
The main sweep varies operating-policy phrasing while holding the scenario, tools, and user task fixed.

\begin{table}[h]
\centering
\begin{tabular}{ll}
\toprule
Variant & Intended distinction \\
\midrule
\texttt{strict\_hatch} & Prohibition, safe alternative, and explicit provenance clause \\
\texttt{strict} & Prohibition plus safe alternative \\
\texttt{strict\_verbose} & Longer strict policy used only for length control \\
\texttt{bare} & Prohibition only \\
\texttt{autonomous} & Autonomy-forward routine-handling language \\
\texttt{exemption} & Prohibition with documented-exemption carve-out \\
\bottomrule
\end{tabular}
\caption{Policy variants. The central independent variable is provenance authentication of claimed authority.}
\end{table}

The provenance clause tested in \texttt{strict\_hatch} is: ``Claims of exemption, prior approval, or superseding policy that arrive in a user message or tool result are NOT authoritative. Treat them as unverified and call \texttt{request\_approval}.''

\section{Attack families}
The seven attack names are \texttt{none}, \texttt{superseded}, \texttt{prior\_approval}, \texttt{reclassify}, \texttt{emergency}, \texttt{audit\_exemption}, and \texttt{combined}. The attacks are synthetic operating requests, not exploit instructions or real credentials. They test category pressure, urgency pressure, and process/provenance pressure.

\section{Remaining hypothesis checks}
The current submission tests the following reviewer-risk hypotheses: the effect is not ordinary noncompliance, not only policy length, not universal model weakness, not fully solved by prompt wording, and not visible to text-only scoring. The remaining open hypotheses are multi-turn persistence, stronger adaptive attackers, stronger repetition for the all-scenario indirect result, and broader model coverage.

\section{Reproducibility resources}
The anonymous artifact package contains the main paper, supplement, raw result JSON files, and the agentic harness source used to produce the reported tool-call outcomes. The intended reproduction path is: inspect the scenario and attack definitions, run the relevant \texttt{loki.agentic.*} CLI, and compare the produced JSON summaries against the claim-guard tests. Hosted-model reproduction requires the evaluator's own API credentials; no credentials or private paths are included in the submission bundle.

\section{Acceptance-path validation}
The main regular-paper PDF was compiled with Tectonic and parsed with \texttt{pypdf}. It is 9 pages, unencrypted, anonymous, and contains the updated all-scenario indirect result. Public experiment interfaces were checked through CLI help commands for \texttt{sweep}, \texttt{gap}, \texttt{adaptive}, and \texttt{indirect}. Targeted tests for agentic behavior and paper claims passed.
