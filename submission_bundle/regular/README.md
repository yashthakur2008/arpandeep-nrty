# AIWILD Regular Paper Submission Bundle

This folder is the local regular-track submission package for:

**Fabricated Authority in the Wild: Policy Provenance as a Control Surface for Tool-Calling Agents**

## Files

- `aiwild_regular_anonymous.pdf`: main 9-page regular-paper PDF.
- `aiwild_regular_supplement.pdf`: anonymous supplement with scenario, policy, attack, artifact, and validation details.
- `extended_anonymous.tex`: source for the main paper.
- `extended_supplement_anonymous.tex`: source for the supplement.
- `LONGER_GROUND_CHECK.md`: novelty and acceptance-odds ground check.
- `LONGER_ACCEPTANCE_VERIFICATION.md`: requirement-to-check and acceptance-path verification.
- `LONGER_ITERATION_VERIFICATION.md`: latest hypothesis/framing validation.

## Submission checklist

- Main PDF is anonymous.
- Supplement is anonymous.
- Main PDF is 9 pages, within the regular-paper limit.
- References/supplement do not count against page limit under AIWILD guidelines.
- OpenReview upload itself still requires user login/session and explicit final confirmation.
