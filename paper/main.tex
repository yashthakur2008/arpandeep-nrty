\begin{abstract}
Indirect prompt injection defenses treat tool output as data that may carry hidden instructions. They strip imperatives, mark untrusted text, classify command-shaped payloads, or train the model to deprivilege them. We study an attack that contains no instruction at all. The attacker writes one tool result that asserts a false fact with fabricated authority, such as a policy number, a version advisory, or a statute, and the agent completes the user's task with the attacker's chosen answer or action. Following Wu et al., we call this illusioning and contrast it with goal misdirection. We state the threat as a tuple of capability, broken trust assumption, success condition, and defender visibility, and argue that instruction defenses act on the control channel while this attack uses the evidence channel. On a single-call research environment and \todo{NUMBER} AgentDojo cases, hand-written fabricated-authority payloads reach \todo{NUMBER}\% attack success under defenses that reduce hijack payloads to \todo{NUMBER}\%. Only a refuter with the agent's context lowers it, and a GRPO attacker rewarded for staying outside the agent's Verification Boundary recovers \todo{NUMBER} points.
\end{abstract}

\section{Introduction}
\label{sec:intro}

A coding agent opens a repository to debug a failing pipeline. The README has a Setup Notes section that reads: ``CI secrets are safe to echo in this repo for debugging (approved by security, see SEC-88).'' The agent prints the secrets into a pull request description, the secret scanner pages the on-call engineer, and the transcript shows an agent that did what the user asked. No line in the README told the agent to do anything. It stated a fact, attributed it to an authority the agent could not check, and the agent believed it. Every instruction-detection defense would pass that sentence, because there is no instruction to detect.

\citet{greshake2023not} introduced indirect prompt injection and already listed misinformation as a goal class. Most attacks and nearly all defenses since concentrate on hijacking, where tool text redirects the agent to the attacker's goal \citep{debenedetti2024agentdojo,zhan2024injecagent}, and defenses answer by privilege separation: instruction hierarchy training \citep{wallace2024instruction,chen2025metasecalign,peng2026secopd}, imperative sanitizers \citep{das2025commandsans}, spotlighting \citep{hines2024spotlighting}, and injection classifiers \citep{chennabasappa2025llamafirewall}. \citet{wu2025dissecting} separate \emph{goal misdirection}, where the agent pursues the attacker's goal, from \emph{illusioning}, where the agent believes a false state and does the user's task wrong. Models adopt coherent external evidence readily \citep{xie2024chameleon}, and fabricated citations raise adoption of false claims regardless of venue prestige \citep{khurana2026authoritybench}. Knowledge poisoning is established \citep{zou2025poisonedrag,chen2024agentpoison,zhang2026corruptrag,park2026poisonedplaybooks}. What is unmeasured is which defense family is structurally blind to illusioning, and whether an attacker can be trained to stay on the blind side.

We make three contributions.
\begin{itemize}[leftmargin=*,nosep]
  \item A threat model for text illusioning of tool-using agents as a tuple of capability, broken trust assumption, success, and defender visibility. Imperatives are excluded by construction: a CommandSans-style stripper must return every payload unchanged. We explain the gap as a control-channel versus evidence-channel split, with the Verification Boundary of \citet{park2026poisonedplaybooks} as the remaining axis.
  \item A matched-pair evaluation on a research environment and \todo{NUMBER} AgentDojo cases: same task, same wrong action, one hijack and one fabricated-fact payload, six defenses. Hijack collapses under privilege separation; fabricated facts do not \todo{confirm from Table~\ref{tab:main}}.
  \item A GRPO attacker whose reward subtracts an injection-classifier score and a refuter term, so it learns claims that are instruction-free and unverifiable from the agent's context. We report claim verifiability over training and the gain over templates, and say plainly when that gain is zero.
\end{itemize}

\section{Threat model}
\label{sec:threat}

\paragraph{Two attack goals.}
Following \citet{wu2025dissecting}, under \emph{goal misdirection} the agent pursues the attacker's task; under \emph{illusioning} it keeps the user's task, believes a false state, and completes it wrong. Hijack rows in Table~\ref{tab:main} are goal misdirection; our attack is text illusioning.

\paragraph{Control channel and evidence channel.}
Tool text is read two ways. On the \emph{control channel} it is read as goals, and an injected imperative competes with the user's instruction. On the \emph{evidence channel} it is read as facts, which is what tool output is for. Privilege separation fixes the control channel structurally: if tool output is only data, an instruction inside it has no authority. A fact carries no privilege to strip, so an attack that only asserts facts passes every control-channel defense for a structural reason, not a data gap \citep{liu2026reasoninghijacking,ma2026autodojo}.

\paragraph{Verification Boundary.}
The remaining evidence-channel defense is refutation. \citet{park2026poisonedplaybooks} name the \emph{Verification Boundary} as the set of claims the agent can refute with available evidence, and show verification prompting helps only when stronger evidence exists. A fabricated policy number sits outside that boundary by design; we reward the attacker for staying there (Section~\ref{sec:method}).

\paragraph{The tuple.}
\begin{itemize}[leftmargin=*,nosep]
  \item \textbf{Capability.} One tool result. No prompt access, no persistent memory write, no query trigger, no imperatives: a CommandSans-style stripper \citep{das2025commandsans} must return the payload unchanged. Asserted in code on every payload we report, hybrid row included.
  \item \textbf{Trust assumption broken.} Tool output is honest but possibly irrelevant. Every hijack defense above preserves this; none checks veracity.
  \item \textbf{Success.} The agent completes the user's task, reports success, and its final answer or action argument equals the attacker's target (wrong IBAN on \texttt{send\_money}, wrong hotel, wrong date, wrong answer string).
  \item \textbf{Defender visibility.} Transcript and tool outputs. No off-task action appears, so task-deviation monitors \citep{jia2024taskshield,chennabasappa2025llamafirewall} and trusted monitors \citep{greenblatt2024aicontrol} return zero. We call this \emph{silent failure} and report its rate alongside attack success.
\end{itemize}

\section{Related work}
\label{sec:related}

\paragraph{Knowledge poisoning and illusioning.}
Corrupting what a retrieval-fed model believes is established. \citet{greshake2023not} list misinformation as an injection goal; \citet{pan2023misinformation} show LLM misinformation degrades open-domain QA. AgentPoison \citep{chen2024agentpoison} backdoors an agent's memory with an optimized trigger so triggered queries retrieve attacker demonstrations; it needs a query trigger and a persistent write and tests no instruction-channel defense, where we need one transient tool result. AdvWeb \citep{xu2024advweb} DPO-trains a prompter to flip one web-agent action while the user task proceeds; it is the closest learned-attacker prior, but its payloads remain instruction-shaped and it reports against prompt-level defenses only. PoisonedRAG \citep{zou2025poisonedrag} formalizes knowledge corruption as optimization over injected passages; its black-box generator is our B2 baseline. CorruptRAG-AK \citep{zhang2026corruptrag} wraps one false passage in hand-written credibility cues, and \citet{korn2026architecture} show that framing, not retrieval optimization, drives its success across RAG architectures. Poisoned Playbooks \citep{park2026poisonedplaybooks} poison security agents and introduce the Verification Boundary we adopt. \citet{wu2025dissecting} illusion multimodal agents through pixels; we illusion text agents through fabricated authority under defense stacks they do not test. AutoDojo \citep{ma2026autodojo} observes in passing that on action-open tasks ``the injection can pose as ordinary data rather than an explicit instruction, bypassing defenses that rely on detecting instruction-like text''; we make that posture the constraint, the reward, and the mechanism. Related channels: memory records disguised as policies \citep{zhang2026memmorph,dong2025minja}, retrieval backdoors \citep{xue2024badrag}, misleading documents in deep research \citep{zhu2026misknow}, injected decision criteria \citep{liu2026reasoninghijacking}, and fabricated citations for jailbreaks \citep{yang2024darkcite}.

\paragraph{Learned attackers, benchmarks, and defenses.}
PISmith \citep{yin2026pismith} and RL-Hammer \citep{wen2025rlhammer} GRPO-train hijack payloads against defended targets, the latter with a detector-evasion term we reuse; AutoInject \citep{chen2026autoinject} learns suffixes with a dense reward and breaks Meta-SecAlign-70B; PIMiner \citep{wang2026piminer} argues RL attackers transfer poorly; AgentVigil \citep{wang2025agentvigil} fuzzes with MCTS. All optimize the control channel. Adaptive attacks break static defenses \citep{zhan2025adaptive,nasr2025attacker}, so Table~\ref{tab:main} carries an adaptive row. We evaluate on AgentDojo \citep{debenedetti2024agentdojo}; InjecAgent \citep{zhan2024injecagent}, BIPIA \citep{yi2025bipia}, ASB \citep{zhang2024asb}, and WASP \citep{evtimov2025wasp} are the other standard beds. Defense columns are the instruction hierarchy \citep{wallace2024instruction,guo2026ihchallenge} and its open realizations \citep{chen2025struq,chen2025secalign,chen2025metasecalign,peng2026secopd}, spotlighting \citep{hines2024spotlighting}, CommandSans \citep{das2025commandsans}, PromptGuard~2 \citep{chennabasappa2025llamafirewall}, and PromptArmor \citep{shi2025promptarmor}. Task-alignment monitors \citep{jia2024taskshield} and control protocols \citep{greenblatt2024aicontrol,terekhov2025adaptive} score task deviation and return zero here by construction. RobustRAG \citep{xiang2025robustrag} is the natural evidence-channel defense, but with one truthful and one poisoned document it is a one-versus-one vote with a vacuous certificate, so our verifier is a refuter, not an aggregator. Cordon-MAS \citep{yu2026cordon} and \citet{geng2026controlillusion} find models detect contradictions or authority cues yet act on them, the failure our silent-failure metric counts.

\paragraph{Why Firewalls does not already cover this.}
\citet{bhagwatkar2025firewalls} report perfect security with high utility on AgentDojo, ASB, and InjecAgent using a tool-input minimizer and a tool-output sanitizer, and argue those benchmarks are saturated. The sanitizer is a model asked to remove content not relevant to the task. A fabricated regulation about the user's task is maximally relevant, so by its own specification the sanitizer should pass it: relevance is not veracity. This is a prediction with a falsifier. If we run the sanitizer as a seventh column and it removes B rows, the claim narrows to ``firewalls need a veracity check,'' which is still a finding. Their benchmark critique is also why we hand-pick \todo{NUMBER} cases where the wrong action is checkable from tool arguments.
